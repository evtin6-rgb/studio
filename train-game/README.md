# Чух-Чух! — паровозик для малышей

Детская игра (2–6 лет): паровозик едет от станции к станции, ребёнок сажает зверят в вагончики,
лопает шарики и собирает звёздочки. Без рекламы, без сбора данных, работает офлайн.

```
web/        игра: HTML5 Canvas + WebAudio, без внешних файлов
android/    Android-приложение (WebView + Google Play Billing 8)
store/      текст карточки и графика для Google Play
```

## Попробовать в браузере
Откройте `web/index.html`. В браузере подписка работает в демо-режиме
(сброс: «Для взрослых» → «Сбросить»).

## Монетизация (ненавязчиво)
- Бесплатно: мир «Луг» и красный паровоз, вся механика игры.
- «Чух-Чух! Плюс» (подписка): 3 мира и 3 поезда, пробный период 7 дней.
- Игру ничего не прерывает: нет всплывающих окон, таймеров и рекламы.
  Платные миры и поезда видны в меню с маленьким замком. Если нажать на них, сначала
  откроется родительский замок: нужно нажать три цифры, написанные словами.
- На экране оплаты указаны цена, период, условия пробного периода и способ отмены,
  как требуют правила Google Play.

## Сборка
GitHub Actions (`.github/workflows/train-game-android.yml`) собирает debug APK и release AAB
при каждом пуше. Готовые файлы лежат в артефактах запуска.

Локально (нужен Android SDK): `cd android && ./gradlew assembleDebug bundleRelease`

## Публикация в Google Play: пошагово

1. **Аккаунт разработчика:** https://play.google.com/console (разовый взнос 25 $).
   Для приёма платежей привяжите платёжный профиль.
2. **Ключ подписи** (один раз, храните надёжно):
   ```
   keytool -genkeypair -v -keystore upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
   base64 -w0 upload.jks   # результат → секрет KEYSTORE_BASE64
   ```
   Секреты репозитория (Settings → Secrets → Actions): `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`,
   `KEY_ALIAS` (=upload), `KEY_PASSWORD`.
3. **Создать приложение** в Play Console: «Чух-Чух! Паровозик для малышей», игра, бесплатное.
4. **Первая загрузка вручную:** запустите workflow вручную (Actions → «Чух-Чух! Android» → Run),
   скачайте `app-release.aab` из артефактов и загрузите его в «Внутреннее тестирование».
   Google требует, чтобы первая сборка была загружена через Console.
5. **Подписка:** Монетизация → Подписки → создать `chuh_plus` с базовыми планами `monthly`
   и `yearly` и пробным предложением (подробности в `store/listing-ru.md`).
6. **Заполнить разделы «Контент приложения»:** политика конфиденциальности (опубликуйте
   `web/privacy.html`, например через GitHub Pages), целевая аудитория (до 5 и 6–8 лет →
   действует программа «Для всей семьи»), реклама — нет, безопасность данных — ничего не собирается,
   возрастной рейтинг (анкета IARC).
7. **Карточка:** тексты и графика из `store/`.
8. **Тестирование:** с 2023 года новые личные аккаунты должны 14 дней тестировать приложение
   в закрытом тесте с 12+ тестировщиками, прежде чем откроется доступ к рабочей версии.
   Добавьте себя в «Лицензионное тестирование», чтобы проверять покупки без оплаты.
9. **Дальнейшие обновления — автоматически:** создайте сервисный аккаунт с доступом к
   Play Console, положите его JSON в секрет `PLAY_SERVICE_ACCOUNT_JSON` и запускайте workflow
   с галочкой «Загрузить AAB в Google Play».

## Что стоит доделать перед большим запуском
- Проверку покупок на своём сервере (Google Play Developer API) — сейчас подписка
  проверяется на устройстве, этого достаточно для старта.
- Озвучку живым голосом (сейчас «голоса» зверят и музыка синтезируются).
