## 4. Обложки: стиль «блокнот музыканта»
Идея взята из вашего мудборда: обложка выглядит как коллаж, склеенный руками, а не как шаблон.
- Ноты, рваная бумага с белой кромкой, скотч, лента клавиш, плёночное зерно, слегка кривые полоски.
- Шрифты (одна пара + почерк):
  - **Cormorant Garamond Italic** — главный заголовок на бумажной полоске;
  - **PT Mono** — «машинописные» полоски-подписи (как «dream on little dreamer» в мудборде);
  - **Caveat** — только для коротких пометок красной ручкой («это я», «листай», номера).
  Все три есть в Google Fonts; Cormorant и Caveat есть в Canva, PT Mono — загрузить.
- Цвета: бумага `#efe4c8`, чернила `#1d1a17`, красная ручка `#c4161c`; фактуры из мудборда:
  бордовый ковёр `#a8140f`, горчичная мешковина `#c9901c`, графит `#3a3a44`, розовый `#f2a7bf`.
- Цвет полоски-рубрики на Reels: бордовый — «Выступления», горчичный — «Как я слышу эту песню»,
  розовый — «До сцены и после», чёрный — «Строю своё имя».
- На обложке Reels всегда вы крупным планом, заголовок — на рваной полоске в нижней трети.
  Главное держать в центре: сетка профиля обрезает Reels до 3:4.
- Шаблоны в `reels/` сделаны на студийных портретах. Для настоящих роликов замените фото на кадр из видео,
  а заголовок на свой хук (3–5 слов). В Canva это: фото на весь кадр → фигура «рваная бумага» → текст Cormorant.

Схема: хук → 1–2 предложения → вопрос зрителю → призыв → 3–5 ключевых слов по теме.

| Лайфстайл | @evtinivan — музыкант в белых очках: сцена, стиль, велосипеды и спонтанный Петербург. |

Ключевые слова: кавер, живое исполнение, пою и играю, необычная версия + «песня — исполнитель»;

закулисье музыканта, подготовка к выступлению, репетиция; жизнь музыканта, Санкт-Петербург, стиль.

## Что из разбора лучше не делать
- Комментировать свои ролики со второго аккаунта: это нарушает правила Instagram.
- Перезаливать один ролик много раз подряд: Instagram режет охват повторов. Лучше перемонтировать с новым хуком.
