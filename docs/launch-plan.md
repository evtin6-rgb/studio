# Как выложить сайт EVTIN Studio и куда ставить ссылку

_Схема для Ивана, 30.10.2026. Адрес сайта: **https://evtinstudio.netlify.app/**_

## 1. Как сайт попадает в интернет

```
Claude правит код  →  ветка claude/studio-audit-fixes  →  PR #16 (превью)
                                                          │
                              ты пишешь «сливай»  ────────┘
                                                          ↓
                                   ветка main  →  Netlify сам выкладывает  →  evtinstudio.netlify.app
```

- **Превью** (видишь только ты и те, кому дашь ссылку): https://deploy-preview-16--evtinstudio.netlify.app. Тут проверяешь всё до запуска.
- **Живой сайт** обновляется сам через 1–2 минуты после слияния PR в `main`. Делать ничего не нужно.
- Если что-то сломалось после запуска: Netlify → Deploys → выбрать прошлый деплой → **Publish deploy**. Сайт откатится за секунды.

## 2. Чек-лист запуска (делаешь ты)

- [ ] Открыть превью с телефона и с ноутбука, пролистать до конца, переключить RU/EN.
- [ ] Если внизу превью висит серый прямоугольник с иконкой листа — это панель комментариев Netlify (Netlify Drawer), а не сайт. Защита сайта не пускает её внутрь, поэтому она серая. На живом сайте её нет. Убрать с превью: Netlify → evtinstudio → **Project configuration** → **Build & deploy** → **Deploy Previews** → **Netlify Drawer** → **Disable**.
- [ ] Написать мне **«сливай»**. Я солью PR #16, и сайт обновится.
- [ ] Отправить себе тестовую заявку через форму на живом сайте.
- [ ] **Formspree** (formspree.io → форма `mnpagjqg`):
  - [ ] письмо пришло на evtin6@gmail.com (проверь «Спам», пометь «Не спам»);
  - [ ] Settings → **Restrict to domain**: `evtinstudio.netlify.app`;
  - [ ] защита от спама включена (ловушка для ботов `_gotcha` на сайте уже стоит).
- [ ] **Google Search Console** (search.google.com/search-console): «Добавить ресурс» → «Префикс URL» → `https://evtinstudio.netlify.app/` → подтвердить → «Файлы Sitemap» → `sitemap.xml`. Так Google быстрее найдёт сайт.

## 4. Что где лежит в коде

```
studio/
├── index.html          главная: тексты EN и разметка всех разделов
├── styles.css          оформление главной и вся анимация (кроме человечка)
├── script.js           переводы RU/EN, меню, форма, анимация при прокрутке
├── buddy.js            нарисованный человечек внизу экрана
├── concept-*.html/.js/.i18n.js   три концепта (Noir, 06:42, Atelier 07)
├── concept.css / concept.js       общее для концептов
├── 404.html            страница «не найдено»
├── assets/             фото и скриншоты (.webp)
├── fonts/              шрифты лежат на сайте, без Google
├── netlify.toml        настройки Netlify: защита, кэш, закрытые файлы
├── robots.txt, sitemap.xml   для поисковиков
├── docs/               заметки и планы (на сайте не открываются)
└── tools/              проверки для Claude (на сайте не открываются)
```

## 5. Как менять тексты

1. Открой таблицу «EVTIN Studio — тексты сайта (правь здесь)»: https://docs.google.com/spreadsheets/d/1XqxPw3VgVP8H1y6HYDX5hPmaSgfn5lzYSTcj4wkr3lo
2. Правь только колонку «Русский». Колонку «Ключ» не трогай.
3. Напиши мне «запускай». Я перенесу текст на сайт, переведу на английский и пришлю превью.

## 6. Позже: свой домен

Когда захочешь адрес вроде `evtinstudio.com`:
1. Купи домен (Namecheap, Reg.ru и т.п.).
2. Netlify → сайт → **Domain management** → **Add a domain**. Netlify подскажет, какие записи вписать у регистратора.
3. Скажи мне: я поменяю адрес в коде, sitemap и превью для соцсетей.
